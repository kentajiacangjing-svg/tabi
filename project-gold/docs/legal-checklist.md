# 公開前 法令確認チェックリスト（ドラフト）

> 本書は開発チームが論点を整理したものであり、法的助言ではありません。**公開前に必ず弁護士等の専門家に確認**してください。
> 届出をすれば全面的に適法になる、という扱いはしません。各論点は「該当するか」「該当する場合に何が必要か」「事業として成立するか」を個別に判断する必要があります。

- 上記 1〜8 のいずれかで「事業として成立しない」「許認可が得られない」となった場合は、仕様の変更（例：対象の見直し、決済の外出し、地域限定）を検討する
- 審査回避のための表現の言い換えや実態の隠蔽は行わない
