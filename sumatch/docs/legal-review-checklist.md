## 3. 連絡先の取扱い（チャット監視・個人情報）

現在の実装：
- 契約成立前は、チャット・見積・契約条件に電話番号・メール・LINE・SNS・連絡用リンクを書くと送信できない（自動判定）
- 契約成立後も、連絡先はチャットでは送れず、契約ページの「連絡先」欄（専用フォーム）でのみ交換できる。相手の連絡先を表示するたびに閲覧記録を残す
- 送信できなかった試みは「誰が・どこで・どの種類」を記録（本文は保存しない）。運営は管理画面で確認できる

確認事項：
- [ ] メッセージ本文の自動判定（内容のスキャン）について、利用規約・プライバシーポリシーへの記載と同意取得の方法
- [ ] 電気通信事業法上の「通信の秘密」との関係（自動判定・運営の閲覧が許容される範囲、事前の包括同意の要否）
- [ ] 運営がチャット本文を閲覧できる運用（通報対応・不正調査）の可否と範囲
- [ ] 連絡先・工事場所の住所の利用目的、保存期間、削除請求への対応、第三者提供（施工会社への提供）の同意
- [ ] 閲覧記録・送信ブロック記録の保存期間

## 6. 追加の確認事項（2026-10-21）

### 現地調査での住所の開示（契約前の例外）
- [ ] 契約前に、訪問先住所を **お客様の明示的な同意** で特定の会社にだけ開示する仕組み（開示先・項目・日時・期限を表示して同意、記録を保存、取り消しと期限後の消去）が、個人情報の第三者提供の同意として十分か
- [ ] 表示期限（仮：訪問日+7日）と消去の扱い
- [ ] 同意文言（画面上は「法務レビュー前の案」と表示中）

### 契約後の連絡先
- [ ] 契約成立後に専用欄で連絡先を交換し、閲覧を記録する運用。表示期限（仮：工事完了+90日）と削除の扱い
- [ ] 運営は連絡先・訪問先住所を見られない設計としている。トラブル対応のために運営が見る必要があるか

### 通信内容の自動判定
- [ ] 公開欄（プロフィール・施工事例・相談内容・口コミ）とメッセージの自動判定。100%の検知はできず、誤判定もありうることの利用者への説明
- [ ] 送信を止めた記録（本文は保存しない）と、連絡先ブロック後に会話が途絶えた案件を運営が「兆候」として確認する運用が、通信の秘密・プライバシーの観点で許容されるか。違反と断定しない運用ルール

### 成功報酬
- [ ] 成果の定義（仮：SUMATCH上の契約成立）、基準額（契約金額・税込）、料率（現在はプランごと 3〜5%）、請求時期、キャンセル・減額・返金の扱い
- [ ] SUMATCH外での契約（直接取引）に対する規約上の扱いと、その確認方法

### 外部サービスへの送信
- [ ] AIの返信下書き（設定時のみ、会話の内容を Anthropic の API に送る）。委託先として利用規約・プライバシーポリシーへの記載が必要か
- [ ] メール送信サービスを使う場合の委託先としての記載

### データの保存期間・削除
- [ ] アカウント・相談・チャット・契約書・バックアップの保存期間と削除請求への対応（削除機能は未実装）
