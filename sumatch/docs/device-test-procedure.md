# 実機テスト手順（iPhone Safari / Android Chrome）

> 状態：**未実施**。この開発環境では実機を操作できません。自動テストは Chromium の Pixel 7 エミュレーション（スマホ幅）だけで、実機の Safari・Chrome・キーボード・カメラ・セーフエリアは確認していません。実施するまで「端末テスト済み」とは扱いません。

## 準備
- テスト環境：ダミーデータの内部テスト環境（デモモードでも可）。実ユーザーの情報は使わない
- 端末：iPhone（最新と1つ前の iOS、Safari）、Android（Chrome）。お客様と施工会社は別の端末
- 記録：各項目の結果（OK/NG）、OS・ブラウザのバージョン、NGならスクリーンショットと手順

## チェック表

記録欄：iPhone / Android それぞれに「OK・NG・日付・担当・スクショ名」を書く。
