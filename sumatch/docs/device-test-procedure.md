# 実機テスト手順（iPhone Safari / Android Chrome）

> 状態：**未実施**（この開発環境には実機がありません）。自動テストは Chromium の Pixel 7 エミュレーションだけで、実機の Safari・Chrome・キーボード・セーフエリアの挙動は確認していません。

## 準備

- 限定テスト環境：`DEMO_MODE=false`、`DATA_ENCRYPTION_KEY` を設定し、HTTPS で公開
- テスト用アカウント：お客様1、施工会社1（審査承認済み、担当エリア・カテゴリ設定済み）
- 端末：iPhone（最新と1つ前の iOS、Safari）、Android（Chrome）。お客様側と会社側で別々の端末を使う

## チェック項目（各端末で実施し、結果・OSバージョン・スクリーンショットを記録）

### お客様
1. トップで工事を選び、予算・時期・場所の質問に答えて登録する（キーボードで入力欄が隠れないか）
2. 会社カードを見て「相談したい」（スワイプとボタンの両方）
3. （会社が対応したい後）マッチ画面 → メッセージ
4. チャットで電話番号を送ろうとして止まること、文章が残ること、「誤判定を運営に知らせる」が開くこと
5. 現地調査：候補日を選び、住所を入力し、同意のチェックを入れてから承認する（日時の表示がずれていないか）
6. 見積が届く → 比較画面（表の横スクロール、項目名の列が固定されること）→ 詳細 → 依頼先に決める
7. 契約条件を確認して同意 → 契約書を開いて（PDF表示）確認 → 契約成立
8. 連絡先欄に登録・削除する
9. 画面の回転、戻るボタン、通知（ベル）、再読み込み後も状態が残ること

### 施工会社
1. 新しい相談を見る → 対応したい → メッセージ
2. 現地調査の候補日を入力（datetime 入力の挙動）→ 承認後に住所が見えること
3. 見積作成（数字キーボード、合計の自動計算）→ 改訂
4. 契約条件の入力 → 同意 → 契約書のアップロード（カメラ・写真・ファイル）→ 確認
5. 連絡先の閲覧、工事開始・完了

### 共通
- 下部ナビ・送信欄・モーダルが、ホームバーやノッチに重ならないこと
- 文字の大きさを最大にしても崩れないこと（iOS の「さらに大きな文字」、Android の「フォントサイズ」）
- 機内モードでの操作時に「通信できませんでした」と出て、復帰後に再操作できること
- ダークモード設定でも読めること（アプリはライト表示）
