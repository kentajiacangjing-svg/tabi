# 公開準備状況（release readiness）— 2026-10-21

「実装済み」は、コードと自動テストで確認できたものだけです。公開環境（ホスティング）と実機では **何も検証していません**（まだ存在しないため）。

## 判定

| 段階 | 判定 | 根拠 |
|---|---|---|
| 内部テスト（ダミーデータ） | **GO** | 自動テストがすべて合格。デモ・テスト用DBは本番と分離。実データを使わない |
| 実ユーザー限定テスト | **NO-GO（条件待ち）** | ホスティング未決定（HTTPS・保存時暗号化・バックアップ未確認）、利用規約・プライバシーポリシーと同意の仕組みがない、実機テスト未実施、運営体制（担当・対応時間）未決定 |
| 本番公開 | **NO-GO** | 上記に加え、法務確認、メール実送信、成功報酬の請求、退会・削除の処理、緊急時対応が未完了 |

## 課題（優先度つき）

### P0（データ漏えい・重複契約など。限定テストを止めるもの）
- 現在、コード上の P0 は確認されていません（今回の監査範囲：権限、二重成立、デモデータの露出、期限切れデータ、ファイルの取得）
- ただし **公開環境での確認は未実施** です。ホスティングを決めたら、HTTPS・保存時暗号化・バックアップを最初に確認します

### P1（実ユーザー限定テスト前に必要）
1. 利用規約・プライバシーポリシーと、登録時の同意取得（文案は法務確認待ち）
2. ホスティングの決定と、HTTPS・保存時暗号化・バックアップ・復元訓練
3. 実機テスト（iPhone Safari・Android Chrome）
4. 運営体制：通報・要確認・退会申請の担当と頻度、問い合わせ窓口（実在する体制が整うまで窓口は表示しない）
5. 退会・削除：保存期間の決定後に、削除・匿名化の処理を実装

### P2（改善）
- 契約書・写真ファイルのアプリ側暗号化（現在はアクセス制御のみ。保存先の暗号化に依存）
- 通知の種類ごとのオン・オフ（現在はメール全体のオン・オフのみ）
- 複数台構成でのリアルタイム通知
- 運営がDBを開いた操作そのもの（SQL直接操作）は記録されない（ホスティングの監査に依存）

## 今回の監査で見つけて直したもの
- 期限切れの住所・連絡先が、画面を開かない限り消えなかった → 1時間ごとの自動消去と `/api/cron/purge`
- ログイン・登録の総当たり対策がなかった → DBで共有する回数制限
- AI下書きが APIキーの存在だけで有効になった → 明示的な設定が必要、送信前に氏名・電話・メール・URLを伏せる
- 非公開ファイルがブラウザに1時間キャッシュされた → `no-store`
- 施工会社の設定画面に「メールでお知らせします」と表示されていた（実際は送らない）→ 文言を修正
- 大きな写真を選ぶと送信後にエラーになった → 選んだ時点で知らせる
